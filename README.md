# About — Balraj Goud Kalal

A personal profile website (Wikipedia-style) built with plain HTML &amp; CSS and hosted for free on GitHub Pages.

## Live site
Once GitHub Pages is enabled: `https://balrajgoudkalal-devops.github.io/About/`

## Files
- `index.html` — all page content and structure
- `style.css` — styling and layout

## Edit locally
Open `index.html` in any browser to preview. Edit the text in `index.html`, refresh the browser to see changes.

## Publish updates
```
git add .
git commit -m "Update content"
git push
```
GitHub Pages redeploys automatically within a minute.
